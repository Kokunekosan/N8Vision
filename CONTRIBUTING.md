# Contributing

Bug reports through GitHub Issues are welcome. Explain how to reproduce the
problem and include your version and environment.

You may modify and share N8Vision under its MIT license. Proposed code changes
can be submitted as pull requests. Publication of a new maintainer release
waits for testing in the separate live installation; an incoming change does
not automatically become a release.

Official alpha I.2t-l-Z1a is under a feature freeze through October 16, 2026.
Limit changes during this period to polishing, bug fixes, compatibility and docs.
