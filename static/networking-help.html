N8Vision Networking

N8Vision serves HTTP. LAN, private port forwarding, and the Cloudflare Public Portal are transports to the same application. Transport access does not create an N8Vision administrator credential.

Local and LAN TCP

Default listener: 127.0.0.1:8189 (host only). Settings → Network → Enable LAN, Save, then restart N8Vision to bind 0.0.0.0:8189. The listener is ordinary HTTP, not HTTPS. Only expose it on trusted networks or inside an encrypted transport. Host firewall rules may need to allow port 8189. For an explicit launch override: python run.py --host 127.0.0.1 --port 8189.

RustDesk TCP tunnel

RustDesk is not an HTTP server and does not provide a public web URL. On a RustDesk client supporting TCP tunneling/port forwarding, create a tunnel from a free local client port (for example 18189) to the N8Vision host's 127.0.0.1:8189 (or its reachable interface). Then open http://127.0.0.1:18189 in the client browser. RustDesk must be running for this tunnel to work. Support and setup vary by RustDesk platform; mobile clients may not expose TCP tunneling. If forwarding through a separate intermediary machine, choose the destination address reachable from that intermediary. A tunnel is not proof of N8Vision Admin status.

Other private transports

SSH example, executed on the client: ssh -N -L 18189:127.0.0.1:8189 user@server, then visit http://127.0.0.1:18189. Tailscale/WireGuard or another VPN can reach the LAN listener via its private IP. Never forward the bare HTTP listener directly to the public Internet.

Cloudflare Public Portal

Settings → Public Portal controls a Cloudflare Quick Tunnel with a browser-accessible HTTPS URL. Install cloudflared separately; N8Vision can locate it on PATH or use a configured path. Public Portal requires device pairing and supports revocation. Quick Tunnel URLs may change when restarted. Do not confuse public access with admin privilege.

Permanent named Cloudflare tunnel

Register a domain and create a remotely managed tunnel in the Cloudflare dashboard. Configure its public hostname to forward to http://127.0.0.1:8189. Save the tunnel token in a file readable only by the N8Vision host account. Under Settings → Public Portal choose Named, enter the public hostname and absolute token-file path, save, then Start Portal. N8Vision runs cloudflared tunnel --no-autoupdate run --token-file PATH. The public hostname must already be configured in Cloudflare; N8Vision does not provision DNS or Access policies. Protect the hostname with Cloudflare Access if appropriate, in addition to N8Vision pairing. Keep the token file outside any web-served directory. Changing tunnel mode requires stopping and restarting the portal.

Pairing and recovery

Pair devices using Settings → Connect Device or Public Portal pairing QR. Pairing and persistent credentials are application-level, not a property of RustDesk, SSH, or Cloudflare. The host-local browser currently has a loopback trust exemption; do not assume a loopback-forwarded browser session is securely distinguishable from a local one. A future host-authorized Admin promotion/recovery mechanism must be separately verified before treating a forwarded session as administrator.

Security notes

Keep the operating system, remote access software, and N8Vision updated. Treat anyone able to control the host OS as able to control its files and processes. Restrict the listener to localhost when only using local reverse tunnels, and avoid publishing TCP port 8189 directly.
